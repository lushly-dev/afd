- [#2358](https://github.com/lushly-dev/afd/pull/2358) [`b79c7e3`](https://github.com/lushly-dev/afd/commit/b79c7e308bfe7e2ad19836a884f9ceb8734a2a85) Thanks [@Falkicon](https://github.com/Falkicon)! - `installVioletTheme()` and `installVioletThemeSet()` adopt the theme as a constructed stylesheet instead of writing a `<style data-violet-theme="runtime">` element ([#1786](https://github.com/lushly-dev/afd/issues/1786)), so a page whose Content Security Policy forbids inline styles needs no exception and no hand-built sheet. Each call appends the sheet to the target's `adoptedStyleSheets` once, never twice; a document and its shadow roots share one sheet, and an iframe's document gets its own. Changing the active set (`installVioletThemeSet`, `resetVioletThemeSet`, or the built-in set arriving from `loadVioletBuiltInTheme`) rewrites every sheet with `replaceSync`, so every root that adopted it switches at once. Presets, product sets, the lazy built-in load and the `violet-theme` host are unchanged.

  - **Breaking (preview minor):** both functions now return the `CSSStyleSheet`, not an `HTMLStyleElement`, and no `style[data-violet-theme="runtime"]` element exists to query or remove. Migrate code that read the element's `textContent` to read the returned sheet's `cssRules`, and code that removed the element to filter the sheet out of `adoptedStyleSheets`. Adopted sheets come after the page's own `<style>` and `<link>` sheets in the cascade, so a page rule that overrides a token on `:root` needs a more specific selector (or set it on an element).
  - **Cascade in shadow roots:** the runtime's sheet is now appended after a shadow root's own `<style>` elements and the sheets already adopted there, where the old `<style>` element could be followed by a host's. A host's override of a token on a `[data-violet-theme-root]` child (or `<violet-theme>`) with equal specificity now loses: raise its specificity or adopt it after the runtime's sheet. Likewise a page's own adopted override sheet must be adopted after `installVioletTheme()`, or use more specific selectors.
