Agent-First Development / Botcore

Agent-First Development: software built as commands that people and agents both call. Not AI that writes your code.

Beta, on PyPI

Botcore

Coding-agent tooling, as one package.
The same in every repo.

Botcore is a Python package a repository installs so the agents coding in it share one kit: lint, test and quality commands that pick the right tool, a skill library that stays current, and three MCP tools.

Status

Beta, on PyPI. lushly-botcore 0.7.0 needs Python 3.11 or later. The botcore-run tool runs the Python it is sent, with your permissions, so it is for a local agent you trust. The command line covers setup, skills and changesets; the lint, test and quality commands are reached over MCP. Linting and testing use the tools installed beside Botcore: it finds ruff or biome, it does not bring them.
