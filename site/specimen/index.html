Specimen

A test bench for components.
Every run leaves evidence.

Specimen renders a component in real Chromium and writes down its markup, layout, styles, state and accessibility tree. Compare two captures to see what changed. It runs Storybook-format stories without Storybook.

Fig. 03The layers

Which layer do you need?
There are three.

The bench knows nothing about AFD and needs none of it. The command layer sits on the bench, and the command line and the server sit on the commands. The project you inspect needs none of them installed.

Endpoints

specimen-cli

The specimen binary. One JSON result on stdout, and exit code 1 when a check fails.

specimen-server

An MCP server over stdio, with every command as a tool. It runs from a checkout for now and is not on npm.

Integration

specimen-afd

The 19 commands and their schemas. The command line and the server both run these.

specimen-fast-af

A plugin for FAST-AF components: their schema, their commands and their themes.

Foundation

specimen

The bench, the comparison, the story runner and the schemas.

specimen-host

The native host, in Rust. It bundles each case, serves it from memory and drives Chromium. One prebuilt package per platform.

No Storybook.

Specimen runs a story the way Storybook's test runner does: compose the annotations, render, run the play, then check accessibility with axe. A story that leans on something Specimen does not reproduce fails. It is never run without it.

Fig. 06The pack

What the runs learned.
Written for an agent.

A component pack is one JSON file for each component and one for the library's shared rules. Specimen builds it from the cases you already run, and every fact in it carries a basis: verified, observed, declared or authored.

  1. specimen pack

    Runs every case twice and writes the records. A case that fails, or shows something different in each pass, contributes nothing.

  2. specimen pack-check

    Builds the same way, writes nothing, and exits 1 when a committed record differs. This is the drift check for CI.

  3. specimen pack-export ./dist

    Adds a catalog with a digest for every record, from the committed files alone. It needs no browser.

As commands 
npm install @lushly-dev/specimen-afd@preview @lushly-dev/afd-core @lushly-dev/afd-server

Status

Preview. On npm under the preview tag, with prebuilt hosts for macOS and for Linux on glibc. On Windows the host builds from source until its package is released. It runs in Chromium only. A diff compares structure, and pixel comparison exists only in the theme audit. The first render that cannot find the browser names the version to install.
