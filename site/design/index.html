Agent-First Design

The design side of AFD

Agents are users too.

Agent-First Design is designing a product for two users: the person who asks and the agent that acts. It is the design side of AFD, an open-source way of building software around commands.

See the patterns The dev side
Four patterns

Design answers for the experience. That used to mean one kind of user. Now a person asks, an agent acts, and both have to find their way through the same product.

01 / The person's side

Intent and authority.

Saying what you want, understanding what was done, deciding what goes ahead and stepping in when it shouldn't.

02 / The agent's side

Legible capability.

Actions it can discover, inputs it can supply, results it can predict and failures it can act on.

03 / The journey they share

One story.

The same identity, state and meaning for both, with the same permission and the same way back, whoever is acting.

Four questions.
Four patterns you know.

What can I do? What comes back? Should this go ahead? What now? Interfaces have answered these for people for decades. An agent needs the same answers, in a form it can read.

01 / Discover

One practice.
Five places it lives.

The same idea, taken to tokens, components, evidence, application chrome and memory. Each has a design side and a dev side.

  • Violet

    Design tokens on a tree. A brand, a product and a theme each inherit, override or remove, and one source exports to CSS, Swift, Kotlin and more.

    Preview, on npm Try the tree

  • FAST-AF

    A component library where each component has a record an agent reads before it uses one.

    Preview, on npm See every component

  • Specimen

    A bench that shows what actually rendered, so two versions of a component are compared on evidence.

    Preview, on npm Compare two versions

  • Loam

    One application chrome for many apps: layout, a command palette and a shared UX library, on a Violet theme.

    In development Read more

  • Umbel

    One MCP server for your repo's agents. Guidance and memory they can cite, with every answer traceable to its source.

Fig. 05The character

A mark that
looks back.

Alfred is the agent's face across AFD. At rest he is a compass: one bar in a ring, leaning like the slash, turning slowly to find you. Come close and he wakes.

Two bars, one angle.
The lean of the wordmark slash never changes.
Two moves.
A bar slides along its axis or changes length. Nothing bends or grows a mouth.
He rests as the mark.
The face appears when he has something to do, then leaves.
