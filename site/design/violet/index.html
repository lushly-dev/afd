Violet

A design token engine.
One tree holds every theme.

Violet keeps your brands, products, light and dark themes and platforms on one tree. Each one stores only what it changes and inherits the rest, so a value you change once reaches everything below it.

Fig. 01The idea

Store the difference.
Inherit the rest.

A design system is rarely one theme. It is a brand, several products, light and dark, touch and pointer. Violet keeps all of them on one tree. Each node holds only what it changes, and everything else comes from the node above.

  1. Inherit

    Say nothing. The value comes from the parent and follows it when it changes.

  2. Override

    The same token with a different value, from this node down.

  3. Add

    A new token, for this node and everything below it.

  4. Subtract

    Take a token away where it doesn't belong. No hover colour on touch.

  5. Reset

    Drop a local change and follow the parent again.

  6. Copy

    Borrow a value from another branch, and keep following it.

      Where the tree
      goes to work.

      • In your repo

        Keep each node as a DTCG file beside your code. No database and no service to run.

        violet --from ./tokens

      • In the terminal

        Export a theme, compare up to four nodes, or run any command by name.

        violet export css atlas-dark

      • In CI

        Check the tokens on every pull request and release them on a tag.

        violet cicd setup

      • In the browser

        Apply a theme as custom properties and switch it at runtime. It follows the system's light, dark and high-contrast settings.

        violet-runtime

      • In an agent

        Every command but validate and doctor is an MCP tool, with the same inputs and results as the terminal.

        violet-mcp

      Start with the command line.

      It reads Style Dictionary and DTCG JSON, so an existing set of tokens can become the root of a tree. 

      npm install --save-dev @lushly-dev/violet-cli@preview

      Status

      Preview. Version 0.3.0-preview.0 is on npm under the preview tag: the engine, the command layer, the command line, the MCP server and the web runtime. The web editor and the Figma plugin are not released yet.
