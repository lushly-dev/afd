How the handoff works

  1. The page calls the chat-connect command through the MCP server's /rpc route.
  2. The command returns a HandoffResult: the WebSocket address and a token.
  3. The page opens the WebSocket with the token.
  4. Messages flow over the socket. Agents that cannot hold a socket use chat-poll and chat-send.
