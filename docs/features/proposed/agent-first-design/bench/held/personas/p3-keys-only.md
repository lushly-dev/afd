# P3: keys only

- **Who:** a long-standing volunteer with a repetitive strain injury who cannot use a mouse or a
  trackpad.
- **Experience:** an expert keyboard user, fast with Tab, Shift+Tab, the arrow keys, Enter,
  Space and Escape. New to this screen.
- **Modality:** keyboard only. You see the screen, and you act only with keys.
- **Stance:** methodical. You work through a screen in order, and you expect it to let you do
  everything you need from the keyboard.
