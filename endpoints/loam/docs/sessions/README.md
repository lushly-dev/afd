# Loam session log

One file per session, added by the pull request that does the work. The rules, the name and the
areas are in [STATUS.md's Session log](../STATUS.md#session-log); the tables the log kept to
2026-11-27 are in the [archives](../STATUS.md#archive). A file looks like this:

```markdown
# Phase 5 step 9a, plugin manifests

- Date: 2026-11-26
- Area: phase 5, bus, copilot and mounted servers
- Pull request: [#2735](https://github.com/lushly-dev/afd/pull/2735), on `t3/loam-plugin-engines-step-9`

What changed, how it was verified (the command or check, and the date) and what is left, in
prose, on as many lines as it needs.
```
