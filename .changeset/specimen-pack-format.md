Add the component pack format, version 0, at `@lushly-dev/specimen/pack`: Zod schemas for a component record, a library's shared rules and its catalog, `checkPack` with a code for each problem, canonical serialization, digests and the catalog writer, and a JSON Schema for each file kind at `@lushly-dev/specimen/pack/<kind>.schema.json`. The package now ships the format's description, `docs/pack-format.md`. Version 0 can change in any release; Specimen does not build packs yet.
