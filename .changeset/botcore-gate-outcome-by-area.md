### Added

- **`gate-outcome-collect` reads the `main` source.** With `sources: [main]`, every fix commit (subject `fix:` or `fix(<scope>):`, either with `!`) and every revert (`Revert "`) that landed on the default branch in the window is read once, through git at the fetched tip, never the working tree: when it landed, its pull request (the number its subject ends with, or the one GitHub says it merged), the units that hold its files, the test paths it touches, the issues its message closes with GitHub's closing words, its `Found-by:` lines where it has them, and the newest date of the lines it replaces, blamed at its parent. No subject, message or diff text is kept. GitHub's GraphQL API then gives, up to 40 numbers to a request and each request counted against `requests`, the issues each pull request closes and every issue's state and labels. Without GitHub the commits are still read and the source is `partly`, with why; asked for with `main`, a `ci` that GitHub cannot be asked for is `absent` instead of a refusal.
- **`gate-outcome-report` reports by area.** With `by: area`, one row for each unit with fix commits (the unit whose manifest's folder holds the files, from `architecture.json` and the manifests under its discovery roots; `repository` where no unit does, `several` with each unit named), most first: fix commits, reverts, escapes (closed issues with a label named `bug` or `security`, or ending `:bug` or `:security`, each counted once), unconfirmed fix commits (that close no issue), commits with a test path (a Rust change inside a `#[cfg(test)]` module counts), and the median age of the last edit with how many commits it was read for. Where GitHub was not read, no escape or unconfirmed count is given. The totals add the commits merged and the escapes by how they were found and by class. The `area` filter lists an area's commits, newest first, with the issues each closes; an area that is not known is refused with the closest names. Every report's `coverage.sources.main` now says how much of the source is held.
