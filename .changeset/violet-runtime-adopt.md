`VioletRuntime.adopt(target?, { preset? })` adopts one constructed stylesheet holding the loaded tokens into a document or shadow root, with `@lushly-dev/violet-elements`' theme selectors (`:root` and `[data-violet-theme-root]`, narrowed to `[data-violet-theme="<preset>"]` when a preset is given), and rewrites it on every `load()` and `switchNode()` ([#1786](https://github.com/lushly-dev/afd/issues/1786)). It writes no inline style, so a page whose Content Security Policy forbids inline styles needs no exception; `unadopt(target?)` removes it. Once `adopt()` is called, `autoApply` no longer writes inline properties and those it already wrote are removed; `removeFromDocument()` now undoes only the inline properties this runtime wrote that still hold its value, restoring the value the page had before the first write; a property the page changed since is left as it is. `adopt()` throws a `TypeError` for a target that is neither a document nor a shadow root, and for a document with no window (one from `createHTMLDocument` or `DOMParser`, or a removed iframe's); a refused call changes nothing. A sheet that can no longer be rewritten is reported with `console.error` and dropped, and the others are still rewritten.

Adopted sheets come after a document's or shadow root's own `<style>` and `<link>` sheets, and `adopt()` appends after the sheets already adopted there: a page's own adopted override sheet must be adopted after it, or use more specific selectors, and in a shadow root a host's `<style>` that overrides a token on a `[data-violet-theme-root]` child with equal specificity loses to it. A token set on `body` is overridden again inside a descendant `[data-violet-theme-root]`. The returned sheet belongs to the runtime: each load and switch rewrites it, so an edit made to it lasts until then, and a repeated `adopt()` does not undo it.

`applyToDocument()`, `removeFromDocument()` and the `autoApply` option are deprecated in favour of `adopt()` and will be removed in a later release; `autoApply` still defaults to `true` until then.
