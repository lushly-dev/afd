### Changed

- **`botcore-memory` keys agent memory on the caller a host verified.** This covers calls through a Botcore host: a host's CLI, its MCP `call` tool, its HTTP surface and an LLM session's bridged tools. Such a call reads and writes agent memory as the host's actor, `<kind>_<id>` for an id of lowercase letters, digits, `_` and `-`, else `<kind>-<digest>` (as for `Alex` or `lane@random`; `botcore_memory.access.principal_id` gives it), so two callers of one host keep separate memories, including ids that differ only by case. A host call whose actor has no id is refused with `MEMORY_PRINCIPAL_UNKNOWN` and a suggestion instead of sharing the `default` memory. The `botcore` CLI, the legacy stdio MCP server's `run` tool and scripts still run as the single local user, `default`, and existing `default` entries stay readable there. The package now requires `lushly-botcore>=0.8.0`, whose hosts name each caller; on an older Botcore a managed host call is refused rather than treated as local. Scope ids and keys with a trailing newline are refused.
- **`botcore_memory.migrate.move_default_memory(to)`** copies the local `default` agent memory to a principal: it backs up both stores and reports the backups, writes the target store once, keeps every entry's fields, treats identical target entries as already moved (so a rerun completes an interrupted move), refuses target keys holding other entries, verifies the copy and never deletes. It refuses host calls; stop hosts serving the store before running it.
- **`botcore-llm` tool calls carry the session's agent name.** For a local, trusted caller such as the `botcore-agents` orchestrator, `llm_session_create(agent_name=...)` is the tool caller's id wherever the tool host's actor gives none (`bridge_commands` and `model_actor` take `agent_name`); a host whose agent actor has an id keeps it. Inside a host call that names its caller, `agent_name` only labels the session. The name identifies the agent, not the person: two people whose tool hosts run the same agent name share that agent's memory.
