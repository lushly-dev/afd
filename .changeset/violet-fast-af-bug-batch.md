Fix five component defects ([#1577](https://github.com/lushly-dev/afd/issues/1577), [#1578](https://github.com/lushly-dev/afd/issues/1578), [#1579](https://github.com/lushly-dev/afd/issues/1579), [#1377](https://github.com/lushly-dev/afd/issues/1377), [#1197](https://github.com/lushly-dev/afd/issues/1197)):

- **Breaking: token interface version 3 ([#1577](https://github.com/lushly-dev/afd/issues/1577)).** `tokens/interface.json` bumps to `contractVersion` 3, adding `color.accent.background` and `color.accent.text` so `<violet-badge color="accent">` uses a distinct blue hue in light (`#146ba0` on `#e2edf5`), dark (`#9fd4f5` on `#182b3a`) and high-contrast (`#004A80` on `#ffffff`) presets instead of matching `success` mint. Product theme sets should supply both ids before upgrading (on the preview line this ships as a minor; `findVioletThemeSetGaps` lists missing ids and components fall back to the built-in light values until supplied).
- **`violet-checkbox` accessible name and description ([#1578](https://github.com/lushly-dev/afd/issues/1578)).** Associate the slotted label with the inner input via `<label for>` instead of duplicating it into `aria-label` or wrapping the `supporting` slot inside `<label>`, so the label is announced once and supporting text remains description-only.
- **`violet-checkbox` and `violet-radio` minimum width ([#1579](https://github.com/lushly-dev/afd/issues/1579)).** Size the label track with `auto 1fr` and `overflow-wrap: break-word` without clamping `.content` to `min-inline-size: 0`, so table cells and content-sized containers include the label's longest word in their minimum width.
- **`violet-combobox` dynamic options and label edits ([#1377](https://github.com/lushly-dev/afd/issues/1377)).** Observe the host's light DOM for nested options added inside `violet-option-group` and edits to an option's text, `label` attribute or `value` attribute so the input and visible list stay reconciled.
- **`violet-data-grid` short-grid editing overlays ([#1197](https://github.com/lushly-dev/afd/issues/1197)).** Flip `.cell-editor-hint` and `.cell-editor-error` above the editing cell (`data-placement="above"`) when there is not enough room below inside `.table-scroll`, preventing clipping and extra scroll overflow on the last rows of a short grid.
