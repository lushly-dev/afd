The contract is now a core and 13 optional, versioned profiles, listed in [`registry.md`](./registry.md) and its machine-readable copy [`registry.json`](./registry.json) (#1925; decisions AR1 and AR4 of the architecture review). The core is result and errors, dispatch, validation, batch and pipeline, exposure and the meta-tools. The profiles are `authorization`, `tasks`, `output-budgets`, `approvals`, `app-calls`, `resources-and-skills`, `plugin-manifest`, `contexts`, `streaming`, `confirmations`, `journal`, `idempotency` and `http`, each at version `1.0`. Every file under `spec/` that states the contract, every shared error code and every capability ID has one owner (the files that describe the contract, such as the READMEs, `VERSION` and this changelog, are listed outside it), and `scripts/check-spec-registry.mjs` checks it in `pnpm check`. Owning a rule is kept apart from requiring it: every implementation still defines all 53 error-code constants and still refuses a command with a declared approval policy that no approval step admitted (`APPROVAL_UNAVAILABLE`, dispatch rule 9), with or without the `approvals` profile. The error codes keep the `profile` values `vectors/error-codes.json` already carried.

Pages split so each has one owner: confirmations, approvals, tasks and app-to-app calls move out of [`command-metadata.md`](./command-metadata.md) into [`confirmations.md`](./confirmations.md), [`approvals.md`](./approvals.md), [`tasks.md`](./tasks.md) and [`app-calls.md`](./app-calls.md), and the command's `scopes` field into [`authorization.md`](./authorization.md). Extra tool `_meta` (T1 to T3) and advertised schemas (V1, V2) move out of [`mcp-resources.md`](./mcp-resources.md) into the core page [`mcp-tools.md`](./mcp-tools.md). Contexts in the tool strategies, with hybrid rule H4, move into [`contexts.md`](./contexts.md). New pages [`streaming.md`](./streaming.md) and [`http.md`](./http.md) gather what the contract already said about those profiles. Every rule keeps its text and its number; no vector, fixture, wire field or error code changes, so the version stays.
