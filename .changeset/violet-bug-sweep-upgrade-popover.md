Fix component defects from the Loam console, review and theme passes ([#2183](https://github.com/lushly-dev/afd/issues/2183), [#1172](https://github.com/lushly-dev/afd/issues/1172), [#1424](https://github.com/lushly-dev/afd/issues/1424), [#712](https://github.com/lushly-dev/afd/issues/712), [#1436](https://github.com/lushly-dev/afd/issues/1436)):

- **Markup mounting ([#1172](https://github.com/lushly-dev/afd/issues/1172)).** Parsed markup upgrades in tree order, so `violet-tabs` connected before its `violet-tab` children were upgraded and threw `tab.syncPresentation is not a function`, and `violet-combobox` threw reading an option's label from its `value` attribute's change callback. `violet-tabs` now upgrades its children when it connects and imports `violet-tab` and `violet-tab-panel` itself, as the other composites import theirs; `violet-select`, `violet-combobox` and `violet-listbox` upgrade their options when they read them.
- **`violet-select` and `violet-combobox` popups ([#712](https://github.com/lushly-dev/afd/issues/712)).** The list opens in the top layer as a manual popover, so an ancestor with `contain`, a transform or clipping no longer moves or cuts it. A `::part(panel)` override that repositioned it inside such an ancestor should go: a top-layer panel with `position: absolute` is placed against the page.
- **`violet-listbox` press ([#712](https://github.com/lushly-dev/afd/issues/712)).** Focus from a press on the list no longer scrolls the active row into view, which moved the row under the pointer so the click landed on another; focus from the keyboard or from script still does.
- **`violet-date-picker` and `violet-time-picker` partial entries ([#712](https://github.com/lushly-dev/afd/issues/712)).** Re-entering one segment no longer erases the others: the input reads `""` while a segment is incomplete, and a value binding wrote that back.
- **`violet-checkbox` hit area ([#1424](https://github.com/lushly-dev/afd/issues/1424)).** The decorative box takes no pointer events, so a role-based click (`getByRole('checkbox').click()`) reaches the native input instead of timing out on the box.
- **`violet-file-upload` forced colours ([#2183](https://github.com/lushly-dev/afd/issues/2183)).** The surface opts out of colour adjustment, so its drag-active, focused, invalid and disabled states drew author colours; they now draw `Highlight`, `LinkText` and `GrayText` with no shadow, hover stays on `ButtonText` and `Canvas`, the copy inside draws `CanvasText`, and the Browse button takes its own forced colours instead of inheriting the opt-out.
- **Theme reach ([#1436](https://github.com/lushly-dev/afd/issues/1436)).** `radius.round` now reaches the color and date pickers' round controls, and `space.stack.xs` the conversation components' smallest gap, which were constants.
